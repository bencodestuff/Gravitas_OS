Bizcat — an 8x16 bitmap font
============================

Bizcat is a retro 8x16 bitmap font by Robey Pointer
<robey@lag.net>, intended for hobby computers or terminals
that use a 640x480 graphics mode, like the Linux VGA console.

  https://robey.lag.net/2020/02/09/bizcat-bitmap-font.html

It is available under a Creative Commons "share and adapt"
license, so feel free to tweak it or use it in your own
projects. (The author's words: https://robey.lag.net/2020/02/09/bizcat-bitmap-font.html)

This copy (files/fonts/bizcat.psf) is the Linux console PSF
variant from the fonts/ folder of Robey's "font-problems"
toolset, used unmodified in the Gravitas OS kernel console.

If you make any significant changes, Robey would love to see
them.
